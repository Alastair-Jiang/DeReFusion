## 2. 五条不可协商的规则（都来自已经踩过的坑）

1. **单一写者（single writer）**：一份产物只有一个写者。仓库、账本、状态文件各自指定唯一 owner；另一方只读、只提"提议"，不直接改。
   - *踩过的坑*：Codex 的克隆 `origin/main` 引用过期 → 两份额外分叉；本地仓库由我独写才不会打架。
2. **能力归属，而非便利归属**：任务给"那台机器能力对得上"的一方，而不是"顺手"的一方（例如取数给出网通的一方）。
3. **长任务加锁 + 幂等**：同一批实验不得两个实例同时跑。
   - *踩过的坑*：批处理曾出现重复实例；后来用"有 run 在跑就退出"的自愈启动器解决——**这个锁必须由任务 owner 持有**。
4. **交付物 = 产物 + 提交哈希 + 账本条目**，不用聊天内容当凭证。
   - *踩过的坑*：口头/聊天式交接导致"未完成项被当成已完成"。
5. **校验是独立角色**：校验方只依据**原始产物**（raw CSV/JSON/npy）复算，不依据对方的总结；且校验范围要**事先写死**，避免"挑着验"。

## 4b. 备用机制（不启用）

1. **产物归属账本**：沿用 lobster-link 的 `TASK-LEDGER.md` 形式，新增一节"DeReFusion 产物 → owner → 状态"，编号权仍在我。
2. **交接协议**：`HANDOFF-<n>.md`（要求方写：目标 / 交付物 / 验收判据 / 截止）+ `RECEIPT-<n>.md`（执行方写：状态 / 证据 / 未做部分）。**不用聊天内容做凭证**。
3. **锁**：长任务由 owner 持锁（本机已是"有 run 在跑就跳过"的自愈启动器；外派任务由对方持锁并在账本登记）。
4. **校验请求模板**：只能引用**原始产物路径 + 事先写死的校验项**。
5. **停止门**：任一方的产物若未按协议交付 → 暂停向它派新任务并出 `*-EXCEPTION.md`（沿用现有规程）。

## 5. 不建议的做法（会直接复现已发生的故障）

- ❌ 两个实例同时写同一仓库/同一克隆（分叉、丢改动、提交冲突）
- ❌ 两个实例都对同一批实验设自动触发（重复跑、CPU 互相拖死）
- ❌ 让校验方基于"总结"验收（等于自审）
- ❌ 把重 GPU / 需 Linux 的任务派给 83JM（无独显、无 WSL）
- ❌ 让规则作者给自己做独立校验（结构上无效）

## 7. C1 轮任务分配结论（2026-09-14，队列锁定之后）

**纠正一个过时的判断**：83JM **能**跑框架训练。`T001` 在其上完成 6 个 DeReFusion 消融 run（两 lane，~56–67 分钟墙钟/run，`ALL DONE exit=0`），并自带 stall 监控重启。
所以"83JM 不能接训练类任务"是**过宽的**：它不能做的是 **GPU 工作**与**需 Linux 的工作**。CPU 训练在范围内，
⇒ 常驻规则（计算默认给 geng、**整体**交付、不拆解）适用于 C1。

### 推荐：**C1（完整 20×2×3 = 120 run 面板）作为一个任务整体交给 geng**

不按 seed 或资产组拆开 —— 规则 2 禁止为分摊算力而拆解。

角色划分（**这样迁移执行权才不会丢掉独立性**）：

| 谁 | 做什么 | 不做什么 |
|---|---|---|
| **geng** | 在锁定队列上跑冻结协议；交回原始产物（每 run 的 `metrics.npy`、`pred.npy`、`true.npy`、命令行、日志；**不含 checkpoint**）+ 带哈希的逐 run 清单 | 不做分析、不算 predictor、不碰 DeReFusion 仓 |
| **ThinkBook（我）** | 算 predictor（`|ACF1|`，**只用 cutoff 之前**数据，带打印的泄漏检查）、跑 Spearman/LOO 分析、拥有仓与裁定 | 不把分析提前给执行方 |
| **geng（第二遍）** | 用**它自己的原始产物**独立复算逐资产交互效应，与我的数字比对；先算完再看我的分析 | 发现问题只报告，不修缮 |

**诚实的成本**：geng 那台较慢（面板 ~60–120h，本机 2 路并行 ~25–35h）。若主人优先要**吞吐**，则 C1 留本机——
但按规则 2 必须把例外理由**写进任务/计划文件**；那条路保留更强的独立性安排（执行方 ≠ 校验方），代价是占用本机约 1.5 天。

**数据与产物传输**：队列已在 geng 自己的目录且有逐文件 SHA-256（见锁定表）；它需拷入其 DeReFusion 克隆的 `dataset/`，
**运行前重验哈希**。产物按 seed 打包回传（约 18MB，不含 checkpoint）；若 syncthing 不可用，走 lobster 仓。
